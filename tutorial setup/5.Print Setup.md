## print Setup

Untuk menghubungkan printer dengan aplikasi erpnext, kita bisa mencoba dan melihat dari artikel berikut:

```
https://docs.frappe.io/erpnext/raw-printing
```

Untuk langkah pertama, mari kita download aplikasi QZ agar erpnext bisa terhubung dengan perangkat printer:

```
https://qz.io/download/
```

Selanjutnya, anda masuk ke menu print settings, dan ceklis pada bagian "enable raw printing"

[[gambar/print%20modul.png]]

Kemudian, untuk membuat format cetak, silahkan anda masuk ke menu print format list

[[gambar/search%20menu%20print%20format%20list.png]]

dalam menu ini, silahkan ceklis custom format dan raw printing, Kemudian isi bagian lainnya sesuai dengan apa yang ingin anda lakukan format custom print

[[gambar/print%20format%20custom1.png]]
