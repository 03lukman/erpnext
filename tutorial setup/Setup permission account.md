## Setup Permission Account

Untuk setup permission account, silahkan masuk ke halaman administrator, kemudian masuk ke fitur search dan cari user list (pastikan setup halaman aplikasi anda berbahasa inggris)

[[gambar/erp_search.png]]

Setelah masuk, silahkan pilih user yang ingin diberikan akses

[[gambar/erp_user.png]]

Masuk ke halaman roles & permissions, dan pilih role profile user tersebut, serta pilih akses apa saja yang akan diberikan.

[[gambar/erp_user%20permission.png]]

Kemudian masuk ke halaman user tersebut, dan user sudah bisa mengakses sesuai dengan rule dan permission yang sudah diberikan oleh administrator, seperti pada gambar berikut:

[[gambar/erp_home.png]]
